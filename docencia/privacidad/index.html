Política de tratamiento de datos personales

Esta política explica qué información se recopila cuando una persona verifica su correo para descargar recursos de JuanKLoz Docencia, para qué se utiliza y cómo puede ejercer sus derechos.

Responsable Datos recopilados Finalidades Clasificación Proveedores Conservación Derechos Seguridad

1. Responsable del tratamiento

El responsable de la base de datos es Juan Carlos Lozano Sierra — JuanKLoz.

Canal electrónico para consultas, actualización, corrección, revocatoria de la autorización o solicitud de supresión: Juankloz75@hotmail.com .

2. Datos que se recopilan

  • Correo electrónico verificado.
  • Dominio del correo.
  • Clasificación institucional calculada.
  • Tipo de usuario declarado.
  • Institución declarada por usuarios externos.
  • Curso de interés.
  • Documento descargado y fecha de la descarga.
  • Constancia de autorización y suscripción opcional.

No se solicitan documento de identidad, código estudiantil, dirección, teléfono, calificaciones ni datos financieros.

3. Finalidades

  • Verificar que la persona controla el correo ingresado.
  • Permitir el acceso automático a recursos descargables.
  • Registrar y medir el uso de los documentos.
  • Conocer la distribución general de usuarios por institución y tipo.
  • Mejorar los cursos, recursos y estrategias educativas.
  • Enviar novedades académicas únicamente cuando la persona marque la autorización opcional correspondiente.
  • Atender consultas, solicitudes y reclamos.

Los datos no se utilizarán para decidir calificaciones, matrícula, admisión o permanencia académica.

4. Clasificación institucional

La clasificación se realiza automáticamente con el dominio del correo verificado:

  • @unisangil.edu.co: usuario verificado de UNISANGIL.
  • @unitropico.edu.co: usuario verificado de UNITRÓPICO.
  • Cualquier otro dominio: usuario externo verificado.

Esta clasificación no certifica matrícula, programa, semestre, vinculación laboral ni pertenencia a una asignatura específica.

5. Proveedores tecnológicos

El sitio público se publica mediante GitHub Pages. La autenticación, base de datos y almacenamiento privado de los documentos se gestionan mediante Supabase.

Estos proveedores procesan información técnica necesaria para prestar sus servicios. La infraestructura tecnológica puede implicar almacenamiento o transmisión internacional de datos según la región y configuración de los servicios contratados.

Cuando se active una herramienta de analítica, no se enviarán correos, nombres ni otros datos directamente identificables a dicha herramienta.

6. Conservación y eliminación

La información se conservará mientras resulte necesaria para las finalidades descritas, exista una relación de uso con la plataforma o sea necesario mantener evidencia de la autorización y de las solicitudes atendidas.

El titular puede solicitar la supresión de sus datos. La solicitud será evaluada de acuerdo con las obligaciones legales aplicables y con los registros que deban conservarse para acreditar el cumplimiento de dichas obligaciones.

7. Derechos del titular

La persona puede solicitar:

  • Conocer los datos personales almacenados.
  • Actualizar o corregir información inexacta.
  • Conocer el uso dado a sus datos.
  • Solicitar prueba de la autorización.
  • Revocar la autorización cuando proceda.
  • Solicitar la supresión de los datos cuando proceda.
  • Presentar consultas o reclamos.

Las solicitudes deben enviarse desde el correo relacionado con la cuenta o incluir información suficiente para verificar la identidad del solicitante.

8. Seguridad y acceso

Se aplican autenticación por correo, sesiones temporales, políticas de acceso a nivel de base de datos y almacenamiento privado. Ningún sistema elimina completamente los riesgos, por lo que las medidas se revisarán y actualizarán cuando resulte necesario.

El usuario debe proteger el enlace recibido, evitar compartir su sesión y cerrar el acceso cuando utilice un dispositivo público.

9. Cambios en esta política

Las actualizaciones se publicarán en esta misma dirección y mostrarán una nueva fecha o versión. Los cambios sustanciales podrán requerir una nueva autorización.

Contacto de privacidad

Para ejercer tus derechos escribe a Juankloz75@hotmail.com .
