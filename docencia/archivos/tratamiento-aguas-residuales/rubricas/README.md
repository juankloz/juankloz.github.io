# Rubricas — Tratamiento de Aguas Residuales

Sube aquí únicamente archivos destinados a publicación abierta.

No incluyas:
- nombres o identificaciones de estudiantes;
- calificaciones individuales;
- correos, teléfonos o datos personales;
- documentos internos o restringidos.

Después de subir el archivo, agrega el enlace correspondiente en:
`docencia/cursos/tratamiento-aguas-residuales/index.html`
